# Homework 06 — Function

## วัตถุประสงค์
ฝึก Decomposition — แตกปัญหาเป็นฟังก์ชันย่อยที่เชื่อมกัน

## โจทย์
เขียนโปรแกรม `hw06_discount.py` เขียน 2 function:

1. `calculate_discount(price, percent)` → คืนค่าจำนวนเงินที่ลด (สูตร: `price * percent / 100`)
2. `calculate_final_price(price, discount)` → คืนค่าราคาสุดท้าย (สูตร: `price - discount`)

กำหนด `price = 850`, `percent = 15` เรียกใช้ 2 function ตามลำดับ แล้วพิมพ์:
- บรรทัดแรก: `discount` ปัดเศษทศนิยม 2 ตำแหน่ง
- บรรทัดสอง: `final_price` ปัดเศษทศนิยม 2 ตำแหน่ง

## ตัวอย่างผลลัพธ์ที่ต้องได้
```
127.5
722.5
```

**ข้อบังคับ:** function ต้อง `return` ค่าเดียวเท่านั้น, ห้ามคำนวณทุกอย่างในบรรทัดเดียวนอก function (ต้องใช้ทั้ง 2 function ที่กำหนด)
