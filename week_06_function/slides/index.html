def / parameter / return
parameter รับค่าเข้า, return ส่งค่าออก
python
def add(x, y):
    result = x + y
    return result

print(add(3, 5))

Output:

8
📊 call stack diagram showing add(3, 5) call, parameters bound, and return value flowing back to caller
Slide 3
return หยุด function ทันที
เจอ return ที่ไหน function จบตรงนั้น
python
def bigger(x, y):
    if x > y:
        return x
    return y

print(bigger(12, 7))

Output:

12
Slide 4
Decomposition
แยกงานย่อยเป็น function ของตัวเอง
python
def calculate_area(width, height):
    return width * height

def calculate_perimeter(width, height):
    return 2 * (width + height)

w = 5
h = 3
print(calculate_area(w, h))
print(calculate_perimeter(w, h))

Output:

15
16
Slide 5
Scope
ตัวแปรใน function ไม่กระทบตัวแปรข้างนอก
python
count = 0

def increase():
    local_count = count + 1
    return local_count

print(increase())
print(count)

Output:

1
0
