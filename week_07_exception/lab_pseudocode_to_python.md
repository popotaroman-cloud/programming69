### ข้อที่ 1 (Pseudocode)

**โจทย์**: แอปแกลเลอรีภาพในโทรศัพท์มือถือต้องการฟังก์ชันแปลงข้อความจำนวนพื้นที่ว่างที่เหลือ (หน่วยเมกะไบต์) ที่ผู้ใช้
พิมพ์เข้ามาให้เป็นตัวเลข เพื่อนำไปคำนวณจำนวนภาพที่ยังบันทึกเพิ่มได้ต่อไป

**Pseudocode**:

```
FUNCTION parse_free_storage(text)
    TRY
        free_mb = CONVERT text TO INTEGER
        RETURN free_mb
    EXCEPT ValueError
        PRINT "ข้อมูลพื้นที่ว่างไม่ถูกต้อง"
        RETURN 0
    END TRY
END FUNCTION

PRINT CALL parse_free_storage WITH ("2048")
PRINT CALL parse_free_storage WITH ("สองพันสี่สิบแปด")
```

**โจทย์ให้แปลง**: จงแปลง pseudocode ข้างต้นเป็นโค้ด Python จริงด้วยตนเอง (ใช้บล็อกทดลองรัน/บล็อกดักข้อผิดพลาด
ดักจับ `ValueError`) แล้วรันเพื่อตรวจคำตอบ (คำเฉลยอยู่ในหมวด "เฉลย" ท้ายไฟล์)

### ข้อที่ 2 (คำอธิบายขั้นตอน)

**โจทย์**: ร้านสะดวกซักผ้าหยอดเหรียญต้องการฟังก์ชันคำนวณค่าบริการซักผ้ารวมของลูกค้าหนึ่งคน

**คำอธิบายขั้นตอน**: ให้เขียนฟังก์ชันชื่อ `calculate_laundry_fee` ที่รับพารามิเตอร์สองตัว คือจำนวนถังผ้าที่ลูกค้าเลือก
เป็นข้อความ (`num_loads_text`) และราคาต่อถัง (`price_per_load`) ขั้นตอนการทำงานคือ แปลง `num_loads_text` เป็น
จำนวนเต็มก่อนในบล็อกทดลองรัน แล้วคูณด้วย `price_per_load` เพื่อคำนวณค่าบริการรวม จากนั้นคืนค่าค่าบริการรวมนั้น
กลับออกไป ให้ใช้บล็อกทดลองรันคู่กับบล็อกดักข้อผิดพลาดสองบล็อก คือ ถ้าแปลงข้อความจำนวนถังเป็นตัวเลขไม่สำเร็จ
(`ValueError`) ให้คืนข้อความ `"จำนวนถังผ้าไม่ถูกต้อง"` แทน และถ้าราคาต่อถังมีชนิดข้อมูลที่ไม่สามารถนำมาคูณกับจำนวน
เต็มได้ (`TypeError`) ให้คืนข้อความ `"ราคาต่อถังไม่ถูกต้อง"` แทน จากนั้นให้ทดสอบเรียกใช้ฟังก์ชันนี้ 3 ครั้ง คือ
`("3", 40)`, `("สาม", 40)` และ `("3", None)` (กรณีที่ระบบยังไม่ได้กำหนดราคาต่อถังไว้เลย จึงเป็นค่า `None`) แล้ว
พิมพ์ผลลัพธ์แต่ละครั้งออกทางหน้าจอ

**โจทย์ให้เขียนโค้ด**: จงเขียนฟังก์ชัน Python จากคำอธิบายขั้นตอนข้างต้นด้วยตนเอง แล้วรันเพื่อตรวจคำตอบ (คำเฉลยอยู่
ในหมวด "เฉลย" ท้ายไฟล์)

### ข้อที่ 4 (โจทย์/pain point เท่านั้น)

**โจทย์**: โน้ตบุ๊กเครื่องหนึ่งมีแอปแสดงเวลาที่เหลือก่อนแบตเตอรี่จะชาร์จเต็ม 100% โดยคำนวณจากเปอร์เซ็นต์แบตเตอรี่
ปัจจุบันและอัตราการชาร์จที่วัดได้ (หน่วยเปอร์เซ็นต์ต่อนาที) แต่บางครั้งอัตราการชาร์จที่วัดได้อาจเป็น 0 (เช่น เมื่อสาย
ชาร์จหลุดหรือเสียบไม่แน่น) ทำให้การคำนวณเวลาที่เหลือเกิดปัญหาขึ้น

ให้ออกแบบและเขียนฟังก์ชัน Python เชิงป้องกัน (defensive function) ที่รับเปอร์เซ็นต์แบตเตอรี่ปัจจุบันและอัตราการ
ชาร์จต่อนาทีเป็นพารามิเตอร์ แล้วคืนค่าจำนวนนาทีโดยประมาณที่เหลือก่อนแบตเตอรี่เต็มกลับออกไป โดยฟังก์ชันต้อง
return ค่าเดียวเสมอไม่ว่าจะเรียกใช้ด้วยข้อมูลนำเข้าแบบใดก็ตาม (รวมถึงกรณีที่อัตราการชาร์จเป็น 0) โดยไม่มี
pseudocode หรือขั้นตอนกำกับ ผู้เรียนต้องออกแบบฟังก์ชันเองทั้งหมด ตั้งแต่ชื่อฟังก์ชัน พารามิเตอร์ ไปจนถึงกลไกดัก
ข้อผิดพลาดภายใน (คำเฉลยอยู่ในหมวด "เฉลย" ท้ายไฟล์)

## ระดับกลาง

### ข้อที่ 1 (Pseudocode)

**โจทย์**: ร้านกาแฟมีระบบแลกแต้มสะสมบัตรสมาชิกเป็นเครื่องดื่มฟรี โดยลูกค้าต้องมีแต้มอย่างน้อย 50 แต้มจึงจะแลกได้

**Pseudocode**:

```
FUNCTION redeem_free_drink(points_text)
    TRY
        points = CONVERT points_text TO INTEGER
    EXCEPT ValueError
        PRINT "ข้อมูลแต้มสะสมไม่ถูกต้อง"
    ELSE
        IF points >= 50 THEN
            PRINT "แลกเครื่องดื่มฟรีได้สำเร็จ"
        ELSE
            PRINT "แต้มสะสมไม่พอสำหรับแลกเครื่องดื่มฟรี"
        END IF
    END TRY
END FUNCTION

CALL redeem_free_drink WITH ("60")
CALL redeem_free_drink WITH ("30")
CALL redeem_free_drink WITH ("หกสิบ")
```

**โจทย์ให้แปลง**: จงแปลง pseudocode ข้างต้นเป็นโค้ด Python จริงด้วยตนเอง (ใช้ส่วน else ของ try ตามที่ปรากฏใน
pseudocode) แล้วรันเพื่อตรวจคำตอบ (คำเฉลยอยู่ในหมวด "เฉลย" ท้ายไฟล์)

### ข้อที่ 2 (คำอธิบายขั้นตอน)

**โจทย์**: พิพิธภัณฑ์แห่งหนึ่งมีระบบสแกนตั๋วเข้าชมที่ประตูทางเข้า โดยตั๋วแต่ละใบมีรหัสเป็นตัวเลขล้วน

**คำอธิบายขั้นตอน**: ให้เขียนฟังก์ชันชื่อ `scan_ticket` ที่รับพารามิเตอร์หนึ่งตัวคือรหัสตั๋วเป็นข้อความ (`code_text`)
ขั้นตอนการทำงานคือ ใช้บล็อกทดลองรันแปลง `code_text` เป็นจำนวนเต็ม หากแปลงสำเร็จให้พิมพ์ข้อความ `"รับตั๋ว
หมายเลข <รหัส> เรียบร้อย"` หากแปลงไม่สำเร็จ (`ValueError`) ให้ใช้บล็อกดักข้อผิดพลาดพิมพ์ข้อความ `"ตั๋วไม่
ถูกต้อง"` แทน และไม่ว่าการสแกนครั้งนั้นจะสำเร็จหรือไม่ก็ตาม ให้ใช้ส่วน finally เพิ่มค่าตัวแปรตัวนับจำนวนครั้งที่มี
การสแกน (ประกาศไว้นอกฟังก์ชันตั้งแต่ต้นด้วยค่าเริ่มต้น 0) ขึ้นทีละ 1 เสมอ เพื่อใช้เป็นสถิติจำนวนครั้งที่มีการสแกน
ทั้งหมด ไม่ใช่จำนวนตั๋วที่ถูกต้องเท่านั้น จากนั้นให้ทดสอบเรียกใช้ฟังก์ชันนี้ด้วยข้อความ `"101"`, `"ABC"` และ `"102"`
ตามลำดับ แล้วพิมพ์ค่าตัวนับสุดท้ายออกทางหน้าจอ

**โจทย์ให้เขียนโค้ด**: จงเขียนฟังก์ชัน Python จากคำอธิบายขั้นตอนข้างต้นด้วยตนเอง แล้วรันเพื่อตรวจคำตอบ (คำเฉลยอยู่
ในหมวด "เฉลย" ท้ายไฟล์)

### ข้อที่ 3 (คำอธิบายขั้นตอน)

**โจทย์**: โปรแกรมตัดต่อวิดีโอต้องการฟังก์ชันแปลงข้อความเวลาที่ผู้ใช้พิมพ์เป็นวินาที เพื่อใช้ตัดคลิปที่ตำแหน่งเวลานั้น

**คำอธิบายขั้นตอน**: ให้เขียนฟังก์ชันชื่อ `parse_timestamp` ที่รับพารามิเตอร์หนึ่งตัวคือข้อความเวลาที่ผู้ใช้พิมพ์
(`text`) ซึ่งต้องเป็นตัวเลขจำนวนวินาทีล้วน (เช่น `"90"` หมายถึงวินาทีที่ 90) ขั้นตอนการทำงานคือ ใช้บล็อกทดลองรัน
แปลงข้อความนั้นเป็นจำนวนเต็ม หากแปลงสำเร็จให้คืนค่าจำนวนวินาทีนั้นกลับออกไปโดยตรง หากแปลงไม่สำเร็จ ให้ใช้
`except ValueError as e` ผูกอ็อบเจกต์ข้อผิดพลาดไว้กับตัวแปร `e` แล้วพิมพ์ข้อความข้อผิดพลาดจริงที่ได้จากตัวแปร `e`
โดยตรง (ไม่ใช่ข้อความที่เขียนขึ้นเอง) จากนั้นคืนค่า `None` แทน จากนั้นให้ทดสอบเรียกใช้ฟังก์ชันนี้ด้วยข้อความ `"90"`
และ `"เก้าสิบ"` แล้วพิมพ์ผลลัพธ์แต่ละครั้งออกทางหน้าจอ

**โจทย์ให้เขียนโค้ด**: จงเขียนฟังก์ชัน Python จากคำอธิบายขั้นตอนข้างต้นด้วยตนเอง แล้วรันเพื่อตรวจคำตอบ (คำเฉลยอยู่

### ข้อที่ 4 (โจทย์/pain point เท่านั้น)

**โจทย์**: แพลตฟอร์มเรียนออนไลน์ขายคอร์สเรียนเป็นแพ็กเกจชั่วโมง ลูกค้าที่ซื้อแพ็กเกจแล้วจะมีชั่วโมงเรียนคงเหลือสะสม
ไว้ในระบบ ทุกครั้งที่ลูกค้ากดเข้าเรียนหนึ่งครั้ง ระบบต้องตรวจสอบก่อนว่าชั่วโมงเรียนคงเหลือมากกว่า 0 หรือไม่ หาก
ชั่วโมงคงเหลือหมดแล้ว ระบบต้องไม่อนุญาตให้เข้าเรียน และต้องแจ้งให้ผู้ใช้ทราบผ่านกลไกข้อผิดพลาดขณะรันของ
Python โดยตรง (ไม่ใช่แค่พิมพ์ข้อความธรรมดาแล้วปล่อยให้โปรแกรมทำงานต่อ)

ให้ออกแบบและเขียนฟังก์ชัน Python ที่รับจำนวนชั่วโมงเรียนคงเหลือเป็นพารามิเตอร์ แล้วโยนข้อผิดพลาดขึ้นเองด้วย
`raise` เมื่อชั่วโมงคงเหลือไม่เพียงพอสำหรับการเข้าเรียน หากชั่วโมงคงเหลือเพียงพอให้คืนค่าข้อความยืนยันการเข้า
เรียนกลับออกไปแทน โดยไม่มี pseudocode หรือขั้นตอนกำกับ ผู้เรียนต้องออกแบบเองทั้งหมดว่าจะเลือกใช้ชนิดข้อผิด
พลาดใดและจะเขียนข้อความอธิบายอย่างไร (คำเฉลยอยู่ในหมวด "เฉลย" ท้ายไฟล์)

### ข้อที่ 1 (Pseudocode)

**โจทย์**: เว็บไซต์ประมูลสินค้าออนไลน์แห่งหนึ่งกำหนดว่าราคาที่ผู้ประมูลรายใหม่เสนอเข้ามาต้องสูงกว่าราคาประมูล
สูงสุดปัจจุบันเสมอ มิฉะนั้นถือว่าการประมูลครั้งนั้นไม่สำเร็จ

**Pseudocode**:

```
CLASS BidTooLowError INHERITS FROM Exception
END CLASS

FUNCTION place_bid(current_highest, new_bid)
    IF new_bid <= current_highest THEN
        RAISE BidTooLowError("ราคาประมูลต้องสูงกว่าราคาปัจจุบัน")
    END IF
    RETURN new_bid
END FUNCTION

TRY
    CALL place_bid WITH (500, 400)
EXCEPT BidTooLowError AS e
    PRINT "ประมูลไม่สำเร็จ:", e
END TRY

PRINT CALL place_bid WITH (500, 600)
```

**โจทย์ให้แปลง**: จงแปลง pseudocode ข้างต้นเป็นโค้ด Python จริงด้วยตนเอง (สร้างข้อผิดพลาดที่ผู้ใช้กำหนดเองชื่อ
`BidTooLowError` โดยสืบทอดจาก `Exception`) แล้วรันเพื่อตรวจคำตอบ (คำเฉลยอยู่ในหมวด "เฉลย" ท้ายไฟล์)

### ข้อที่ 2 (คำอธิบายขั้นตอน)

**โจทย์**: ร้านอาหารแห่งหนึ่งเก็บเมนูพิเศษประจำวันไว้ในดิกชันนารีที่มีคีย์เป็นชื่อวันในสัปดาห์ (ภาษาไทย) แต่ละวันมี
รายการเมนูพิเศษของวันนั้นเก็บเป็นลิสต์ (บางวันมีเมนูพิเศษหลายรายการ บางวันมีเพียงรายการเดียว และบางวันไม่มี
การกำหนดเมนูพิเศษไว้เลย)

**คำอธิบายขั้นตอน**: ให้เขียนฟังก์ชันชื่อ `get_special_menu` ที่รับพารามิเตอร์สองตัวคือชื่อวัน (`day`) และลำดับที่
ของเมนูที่ต้องการภายในวันนั้น (`menu_index`) ขั้นตอนการทำงานคือ ใช้บล็อกทดลองรันคืนค่าชื่อเมนูที่ตำแหน่งนั้นออก
ไปโดยตรง โดยใช้บล็อกดักข้อผิดพลาดเพียงบล็อกเดียวคือ `except LookupError as e` เพื่อดักจับทั้งกรณีที่ไม่มีชื่อวันนั้น
อยู่ในดิกชันนารีเลย (ซึ่งจะเป็น `KeyError`) และกรณีที่ลำดับที่ระบุเกินจำนวนเมนูพิเศษที่มีจริงของวันนั้น (ซึ่งจะเป็น
`IndexError`) เมื่อดักจับได้ ให้พิมพ์ทั้งชนิดที่แท้จริงของข้อผิดพลาด (ผ่าน `type(e).__name__`) และข้อความจาก `e`
แล้วคืนค่า `None` แทน จากนั้นให้ทดสอบเรียกใช้ฟังก์ชันนี้ 3 กรณีกับดิกชันนารีที่มีเมนูพิเศษของวันจันทร์ 2 รายการและ
วันอังคาร 1 รายการ คือ (1) ขอเมนูลำดับที่มีอยู่จริงของวันจันทร์ (2) ขอเมนูลำดับที่เกินขอบเขตของวันจันทร์ และ
(3) ขอเมนูของวันอาทิตย์ซึ่งไม่มีอยู่ในดิกชันนารีเลย

**โจทย์ให้เขียนโค้ด**: จงเขียนฟังก์ชัน Python จากคำอธิบายขั้นตอนข้างต้นด้วยตนเอง แล้วรันเพื่อตรวจคำตอบ (คำเฉลยอยู่

### ข้อที่ 4 (โจทย์/pain point เท่านั้น)

**โจทย์**: เครื่องพิมพ์เอกสารของสำนักงานแห่งหนึ่งมีขั้นตอนการพิมพ์เอกสารหนึ่งงานแบ่งเป็นสามขั้นตอนซ้อนกัน คือ
(1) เชื่อมต่อกับเครื่องพิมพ์ (อาจล้มเหลวถ้าเครื่องพิมพ์ไม่ได้เปิดเครื่องอยู่) (2) ตรวจสอบจำนวนหน้ากระดาษที่ขอพิมพ์
เทียบกับจำนวนหน้าที่เหลืออยู่ในถาดกระดาษ (อาจล้มเหลวถ้าขอพิมพ์เกินจำนวนที่เหลืออยู่จริง) และ (3) สั่งพิมพ์เอกสาร
จริง ไม่ว่าขั้นตอนใดจะล้มเหลวหรือไม่ก็ตาม ระบบต้องบันทึกข้อความว่า "ปิดการเชื่อมต่อเครื่องพิมพ์แล้ว" เสมอเป็น
ขั้นตอนสุดท้าย และหากขั้นตอนใดเกิดข้อผิดพลาดขึ้น ระบบต้องบันทึกรายละเอียดข้อผิดพลาดนั้นไว้ก่อน (log) แล้วจึง
ส่งต่อข้อผิดพลาดเดิมนั้นให้ผู้เรียกใช้งานฟังก์ชันได้รับทราบต่อไปด้วย (ไม่ใช่ปิดบังข้อผิดพลาดไว้เฉย ๆ)

ให้ออกแบบและเขียนฟังก์ชัน Python สำหรับระบบนี้ โดยไม่มี pseudocode หรือขั้นตอนกำกับ ผู้เรียนต้องออกแบบเองทั้งหมด
ว่าจะวางโครงสร้างบล็อกทดลองรัน/บล็อกดักข้อผิดพลาด/ส่วน finally ซ้อนกันอย่างไร จะดักข้อผิดพลาดแบบระบุชนิดหรือ
แบบไม่ระบุชนิด (bare except) ตรงจุดใดจึงเหมาะสม และจะโยนข้อผิดพลาดซ้ำ (re-raise) ที่จุดใดจึงจะยังคงส่งต่อข้อ
ผิดพลาดเดิมไปให้ผู้เรียกใช้งานได้รับทราบ (คำเฉลยอยู่ในหมวด "เฉลย" ท้ายไฟล์ — เป็นเพียงหนึ่งในหลายวิธีออกแบบที่
เป็นไปได้)

```python
01  def estimate_minutes_to_full(current_percent, charge_rate_per_minute):
02      try:
03          remaining_percent = 100 - current_percent
04          return remaining_percent / charge_rate_per_minute
05      except ZeroDivisionError:
06          return -1
07
08
09  print(estimate_minutes_to_full(60, 0.5))
10  print(estimate_minutes_to_full(60, 0))
```

```
80.0
-1
```
