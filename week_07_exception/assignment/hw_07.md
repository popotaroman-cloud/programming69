# Homework 07 — Exception (การบ้านสุดท้ายก่อน Oral Defense)

## วัตถุประสงค์
รวมทุกอย่างที่เรียนมาทั้งวิชา — Accumulator + Function + Defensive Exception Handling

## โจทย์
เขียนโปรแกรม `hw07_average.py` เขียน function `safe_average(scores)`:
- ใช้ Accumulator pattern (loop สะสมค่า) หาผลรวมของ `scores` แล้วหารด้วย `len(scores)` เพื่อหาค่าเฉลี่ย
- ใช้ `try`/`except ZeroDivisionError` ป้องกันกรณี `scores` เป็น list ว่าง (`len(scores)` = 0) — ถ้าเป็น list ว่างให้ `return 0`

ทดสอบด้วย:
```python
scores1 = [80, 75, 90, 60]
scores2 = []
print(round(safe_average(scores1), 2))
print(safe_average(scores2))
```

## ตัวอย่างผลลัพธ์ที่ต้องได้
```
76.25
0
```

**ข้อบังคับ:** ต้องใช้ `for` loop (ห้าม `sum()`), function ต้อง `return` ค่าเดียว, ห้าม shorthand syntax ทุกชนิด

## นโยบาย AI (สัปดาห์นี้เปิดเต็มที่)
ใช้ AI ช่วยเขียนได้เต็มที่ **แต่ต้องเตรียมอธิบายทุกบรรทัดได้ด้วยปากเปล่าในวัน Oral Defense** — ถ้าอธิบายไม่ได้ถือว่าไม่เข้าใจ แม้โค้ดจะรันผ่านก็ตาม แนบสรุปสั้น ๆ ท้ายไฟล์ (เป็นคอมเมนต์) ว่าใช้ AI ช่วยตรงไหนบ้าง
