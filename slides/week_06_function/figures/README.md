## วิธีสร้างใหม่ (ถ้าต้องแก้ไดอะแกรม)

1. ต้องใช้ Python ที่มี `matplotlib` ติดตั้งอยู่ (บนเครื่องที่พัฒนาไฟล์นี้คือ
   `C:\Users\wayo\AppData\Local\Programs\Python\Python312\python.exe` — ไม่ใช่ python ตัวที่อยู่บน PATH ปกติ)
2. แก้ค่าคงที่/พารามิเตอร์ในสคริปต์ `gen_figures_*.py` ตามต้องการ แล้วรัน (ตั้ง `PYTHONIOENCODING=utf-8`
   เพราะสคริปต์พิมพ์ข้อความภาษาไทย)
3. **ตรวจดูภาพ PNG ที่ได้ก่อนเสมอ** ว่าไม่มีข้อความทับลูกศร หรือ glyph ภาษาไทยหายไป (ฟอนต์ที่ใช้ได้คือ
   `Tahoma` — ห้ามใช้ `Consolas` กับข้อความที่มีตัวอักษรไทยปน เพราะจะเห็นเป็นช่องว่างหาย)
4. รันสคริปต์ `patch_figures_*.py` ที่คู่กัน เพื่อแทรกรูปที่อัปเดตแล้วกลับเข้า `06_function.html` และ
   `index.html` (ต้องแทรกทั้งสองไฟล์ให้เหมือนกันเสมอ)
5. ตรวจสอบ: `diff 06_function.html index.html` ต้องไม่มีอะไรต่าง, จำนวน `<div>` ต้องเท่ากับ `</div>`,
   และไม่ควรเหลือ `class="placeholder"` ที่ยังไม่ได้แทนที่

หมายเหตุ: ไฟล์ `.md` ต้นฉบับ (`../06_function.md`) ยังคงเก็บข้อความ `[FIGURE: ...]` เดิมไว้เป็น "โจทย์การออกแบบ"
ไม่ได้แก้เป็นรูปภาพ — รูปจริงมีอยู่เฉพาะในไฟล์ `.html` เท่านั้น
