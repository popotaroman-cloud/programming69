ตัวแปรคืออะไร
= คือ "ทับค่าลงกล่อง" ไม่ใช่ "เท่ากับ"
python
age = 20
print(age)

Output:

20
  • สร้างกล่องเก็บค่าในหน่วยความจำ
  • ตั้งชื่อกล่องว่า age

Diagram: กล่องตัวแปร
Slide 4
การทับค่า (Reassignment)
ค่าตัวแปรเปลี่ยนได้ทุกครั้งที่มีการ assign ใหม่
python
x = 5
x = x + 3
x = x * 2
print(x)

Output:

16
  • Trace บนกระดาษก่อนรันเสมอ
Slide 5
Copy ไม่ใช่ Reference
b = a คัดลอกค่า ณ ตอนนั้น ไม่ได้ผูกกล่องเข้าด้วยกัน
python
a = 7
b = a
a = a + 10
print(b)

Output:

7
  • b ยังเป็น 7 แม้ a จะเปลี่ยนไปแล้ว
Slide 6
ชนิดข้อมูล (Data Type)
Python มี 4 ชนิดพื้นฐานที่ต้องรู้ก่อน
  • int — จำนวนเต็ม
  • float — จำนวนทศนิยม
  • str (String — ข้อความ)
  • bool (Boolean — ค่าความจริง)
Slide 7
input() ได้ str เสมอ
ค่าจาก input() เป็นข้อความเสมอ ต้องแปลงชนิดก่อนคำนวณ
python
age_text = input()
age = int(age_text)
print(age)

Output (สมมติผู้ใช้พิมพ์ 25):

25
  • ข้าม int() ไม่ได้ — จะเจอ TypeError ทันที
Slide 8
Operator Precedence
คูณ/หารทำก่อน บวก/ลบเสมอ
python
result = 2 + 3 * 4
print(result)

Output:

14
  • ผลลัพธ์ = 14 ไม่ใช่ 20 (ไม่ใช่ (2+3)*4)
Slide 9
`//` และ `%`
หารปัดเศษทิ้ง กับ หารเอาเศษ ใช้บ่อยมาก
python
print(42 // 3)
print(58 % 8)

Output:

14
2
  • // เก็บแต่จำนวนเต็ม ตัดเศษทิ้ง
  • % เก็บแต่เศษที่เหลือ (ใช้เช็คเลขคู่/คี่ได้)
Slide 10
String Concatenation
+ กับ str คือการต่อข้อความ (คนละความหมายกับ + ตัวเลข)
python
s1 = "Py"
s2 = "thon"
print(s1 + s2)

Output:

Python
  • ต่างจาก f-string ที่จะเรียนสัปดาห์หน้า
Slide 11
ฟังก์ชัน `len()`
ฟังก์ชันในตัว นับจำนวนตัวอักษรใน string
python
text = "Python"
print(len(text))

Output:

6
  • ใช้บ่อยมากตลอดวิชา โดยเฉพาะกับ list ใน Week 04-05
Slide 12
นิพจน์เปรียบเทียบ → Boolean
>, <, == ให้ผลลัพธ์เป็น True/False เสมอ
python
x = 2
y = 19
print(x < y)

Output:

True
  • สัปดาห์หน้า (Week 03) จะเอาค่านี้ไปใช้ตัดสินใจด้วย if
